Data

Datasets available on this website. All files are free to download, and no account is needed.

Datasets

Dataset Description Genomes Formats Updated
ZH13 to Wm82.a4 gene ID conversion One-to-one gene correspondence between ZH13 and Wm82.a4 in both directions, with confidence levels, evidence notes and Wm82.a2.v1 IDs. ZH13, Wm82.a4 Excel, TSV Oct 2026
Abiotic stress RNA-seq expression TPM values and read counts of 192 public RNA-seq samples (14 studies) under salt, drought and heat stress, with differential expression results. Can be plotted on the Expression page. Wm82.a4 TSV Oct 2026
Functional annotation (GO, KEGG, Pfam) GO terms, KEGG pathways and Pfam domains of Williams 82 genes, used for enrichment on the Gene Analysis page. Wm82.a4 TSV Oct 2026

File formats

Format How to open
Excel (.xlsx) Microsoft Excel, WPS Office or LibreOffice Calc. Best for browsing and searching by hand.
TSV (.tsv) Plain text with tab-separated columns. Best for R, Python and command-line tools. Large TSV files can open slowly in Excel, so use the Excel file for browsing.

Using the data

You may use these datasets in your research. If you use them in a publication, please cite this website as shown on each dataset page.

To convert a list of gene IDs without downloading any files, use the Gene ID Converter.
