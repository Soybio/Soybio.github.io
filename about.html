About

Soybio is a website for sharing soybean bioinformatics and genomics data and tools.

About this website

This website shares data and tools for soybean genome research. Current content includes expression data from 192 public RNA-seq samples under salt, drought and heat stress with online bar plots and heatmaps, a gene ID conversion table between the ZH13 and Wm82.a4 genomes, and an online gene ID converter. More datasets and tools will be added over time.

All files can be downloaded freely. No account or registration is needed.

Citation

If you use data from this website in a publication, please cite the dataset as shown on its page, for example:

Soybio (2026). ZH13 to Wm82.a4 gene ID conversion table, version 1.0. Available at https://soybio.github.io/data/zh13-wm82a4/

Contact

For questions, corrections or suggestions, please contact the website owner through GitHub: github.com/Soybio.

Technical information

The website is hosted on GitHub Pages. The Gene ID Converter runs in your web browser, so the gene lists you enter are not sent to any server.
