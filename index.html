Using this website

Data access. All files can be downloaded directly from the dataset pages. No account or registration is needed.

Gene IDs. Data are given for Williams 82 assembly 4 (Wm82.a4). ZH13 and Wm82.a2.v1 gene IDs are converted automatically in the search and analysis pages.

Citation. If you use data or results from this website in a publication, please cite this website and the original studies listed on each dataset page.
